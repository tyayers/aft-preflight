About Apigee Preflight

        

          Apigee Preflight is an interactive developer test console and runtime explorer for Apigee Templater declarations powered by Bungee Runtime. It enables you to inspect proxies, API products, and developer credentials, run live test calls with SSE chunk streaming, and inspect step-by-step policy execution traces in a native Bun execution engine.
        

      


      
      

        
Core Features

        

          

            

              
              Visual Overview
            

            
Clean breakdown of base endpoints, routing rules, upstream targets, and policy execution summaries.

          

          

            

              
              Interactive Test Console
            

            
Send requests with pre-filled headers and payloads, with real-time SSE chunk streaming into the response window.

          

          

            

              
              Deployment Tests & Assertions
            

            
Run declared tests directly from deployment files, validate response status assertions, and inspect pass/fail metrics.

          

          

            

              
              Tracing & Profiling
            

            
Step-by-step waterfall timeline, variable inspect drawer, and Apigee / OpenTelemetry export formats.
